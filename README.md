# odin-recipes
Odin Recipes
This is my first project from The Odin Project. The goal of this project is to build a basic recipe website using HTML.

The website contains three recipes:

Lasagna

Slow Cooker Chicken and Gravy

Honey Glazed Chicken

Through this project, I practiced the fundamentals of HTML, including creating webpages, using headings and paragraphs, adding images, creating links between pages, and organizing content with lists.

Completing this project helped me understand how different HTML elements work together to create a simple website. It also gave me hands-on experience with creating and organizing multiple pages and connecting them through navigation links.

Skills Demonstrated
By completing this project, I demonstrated my ability to:

Create a basic HTML document

Use headings, paragraphs, and lists

Add images to webpages

Create links between webpages

Organize files and folders for a website

Use basic HTML structure and semantic elements

Build a simple multi-page recipe website

This project is a starting point for my web development journey, and I look forward to improving my HTML, CSS, and JavaScript skills as I continue through The Odin Project.
